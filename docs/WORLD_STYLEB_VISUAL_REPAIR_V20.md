# DailyCorp Native 0.20.0 Alpha — городская графика и континент

## Известные дефекты версии 0.19, подтверждённые пользовательскими скриншотами
1. Слишком крупные "декорации" на континенте: источники Pack 1/3/8/10 — иллюстрации целых диорам или рельефов, не изолированные объекты. Они выводились поверх текстур как отдельные объекты.
2. Полосатая и шахматная поверхность города. Временные варианты материала менялись на каждой соседней клетке, а городская застройка наследовала чрезмерные обширные песчаные биомы.
3. Изображения 64px из первого атласа содержали подписи, миниатюры и значки, видимые прямо внутри строений.
4. Старые дороги вырисовывались полной шириной клетки, пересечения накладывались на окружение; один крупный концепт перекрёстка показывался поверх обычных дорог.
5. Визуальная граница вода–земля выглядела лестницей из клеток, а справа подписи городов могли выходить за экран.

## Исправления
- Карта континента остаётся процедурной **с теми же координатами 48 городов**. Подключённый в 0.19 материал World Style B кэшируется в RGB565, а береговая/водная граница сглаживается по интерполированному соседству биомов.
- Континентальные диорамы, которые нельзя использовать как обособленные объекты, больше не расставляются на карте. Никакой 3D-остров посреди сплошной плоской поверхности.
- Материалы городских изометрических ромбов группируются регионами 5×5 вместо смены каждого тайла; для урбанизированной зоны над изначально песчаной землёй используется чистое травянистое основание. Климатическая генерация, ресурсы и координаты не изменяются.
- Процедурные здания имеют общую физическую геометрию, меньший размер и единые окна/фасады. Старая миниатюрная графика с напечатанными текстовыми этикетками не используется в городе.
- Участки на покупку обозначены скромным знаком + на своей клетке без наложения массивных диорам. Взаимодействие и цена покупки не изменены.
- Дороги рисуются связной сетью узких серых полос с тонким бордюром, вместо непропорциональных квадратных перекрёстков и сплошных серых ромбов.
- Декор ограничен редкими изолированными прозрачными деревьями/камнями из Pack 9. Рельефные уступы из Pack 8/10 без height-map не используются, чтобы не возвращать артефакты.
- Зоны возле дорог предварительно вычисляются и кэшируются. Большой условный обход всех дорог для каждой клетки при перерисовке удалён; лишние атласы не декодируются.
- Подписи городов ограничены границами экрана, часть подписей зданий у верхней панели скрывается.

## Совместимость
- Не менялись GameState, serialVersionUID, сохранения Mine1/Mine2, механика шахт, вагонеток, лифтов, контракты и транспорт.
- По умолчанию включена проверенная графика Style B, но неподходящие иллюстрационные компоненты больше не применяются автоматически.
