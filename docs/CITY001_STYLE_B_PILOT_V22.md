# DailyCorp Native 0.22 — тестовый макет города 001 (Style B)

## Цель
Реальный визуальный пилот для `city_001` в Kotlin/Android Canvas.
Никаких Godot-зависимостей. Остальные 47 городов используют прежний план.

## Что подключено
- `City001Layout.kt`: отдельное расширение локальной схемы 36×34;
  центральная дорожная петля, свободный зелёный район, детерминированная
  расстановка скверов, городской мебели и грузовых площадок.
- `MapCanvasView.kt`: для cityId=1 используется план пилотного города,
  реальные иллюстрированные здания/дома/городская мебель из существующего
  атласа `dailycorp_resources.webp` посредством `GameArt`.
- Основа рельефа и редкий природный декор по-прежнему используют ранее
  утверждённые `WorldStyleBArt` / `WorldStyleBAtlas` (Style B Packs 01–10).
  Серые геометрические здания сохранены как аварийный запасной рендер.
- Для города 001 дорога получает выразительные светлые бордюры;
  верхняя панель отмечает тестовый макет.

## Совместимость
- `City.lots` (включая идентификаторы, типы, координаты, въезды) берётся
  напрямую из сохранённого `City`, не генерируется повторно.
- Старые дороги сохраняются; новая центральная петля добавляет сегменты,
  не пересекая занятые участки и их ближайшие основания.
- Декорации никогда не являются игровыми строениями и не влияют на
  маршруты, покупки, запасы, контракты, автопласты, лифты и Mine2.
- Сериализуемые GameState/City/Lot не изменены; миграция сейвов не требуется.
- Изменения дизайна не распространяются на `cityId != 1`.

## Тестирование
Автоматические проверки: `City001LayoutTest.kt` проверяет сохранение
каждого игрового лота и дорожного въезда, отличие новой дороги, повторяемость
генерации, отсутствие декораций поверх предприятий и пустых построек.
Тестируйте на телефоне отдалённый и ближний масштаб, тапы по зданиям,
покупку шахты, маршруты грузовиков и прокрутку карты.

## Ограничения пилота
Изображения строений из старого иллюстрированного атласа используются с
обрезкой встроенных подписей; часть объектов всё ещё требует выделенных
HD-спрайтов Style B без встроенных текстов. Это первая визуальная
интеграция, а не окончательный набор графики всех городов.
