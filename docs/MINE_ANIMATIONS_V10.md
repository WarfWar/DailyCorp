# DailyCorp Native 0.10.0 — шахтные анимации и добыча по единице

## Управление шахтой 2.0
- Обзор **всегда активен**: один палец перемещает карту, два пальца масштабируют.
- **Одно нажатие** на разведанную породу выделяет клетку, **второе нажатие на ту же клетку** назначает добычу; второе нажатие на уже назначенную клетку отменяет задание.
- Кнопки «Обзор» и «Проходка» убраны; кнопка «Разведка ₽» временно включает выбор платной точки и затем автоматически возвращает обычные касания.
- По-прежнему доступны найм бригад, улучшения и просмотр глубины.

## Рудный блок
- Показывает, сколько **единиц руды осталось**, а также полоску выполнения текущего бурового цикла.
- Каждый успешно завершённый цикл извлекает **ровно одну единицу** руды для одного проходчика.
- При наличии запасов клетка остаётся рудной, задание сохраняется, твёрдость для следующей единицы восстанавливается.
- По мере истощения единицы переходят в локальный испытательный запас Mine2; после последней единицы клетка становится тоннелем.
- Старая сериализуемая модель сохраняется без новых обязательных полей, чтобы не сбрасывать старые шахты.

## Анимация
- Пользовательский ZIP DailyCorp_SideView_GIF_Integration_v1 использован в качестве исходника: 16 групп состояний шахтёров и вагонеток.
- Из настоящих PNG-кадров собран оптимизированный маленький WebP-атлас с четырьмя фазами каждой анимации, расположенными по строкам.
- Пример MineFrameAnimator.kt адаптирован в MineSpriteFrames.kt, который декодирует один общий Bitmap и выбирает фазы на Canvas без дополнительных зависимостей.
- Движение шахтёров в Mine2 выбирает idle/walk/mine и направление; Mine1 использует новые кадры для работников и вагонеток (пустых и нагруженных).
- В Mine2 вагонетки пока отсутствуют как физические объекты — их новые спрайты будут задействованы при подключении внутренней логистики.
- Компактное изображение служит оптимизированным прототипом: часть мелких деталей исходного спрайта потеряна при уменьшении, оригинальный архив пользователя остаётся источником для следующего HD-атласа.

## Обратная совместимость
- Старый игровой мир, экономика, фабрики, контракты и резервная шахта 1.0 остаются.
- Новая добыча Mine2 не переводится автоматически в городскую логистику.
- При отсутствии/ошибке декодирования арт-атласа отрисовываются запасные фигуры, механика игры остаётся работоспособной.
