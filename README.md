# DailyCorp ⛏️

Мобильная экономическая стратегия о шахтах, добыче руды и перевозках. Авторский прототип на **Godot 4.4** для Android.

## Что есть в версии 0.1

- Процедурно сгенерированная 2D-шахта с углём, медью, железом и золотом.
- Выбор клеток для раскопки касанием; движение шахтёров по тоннелям.
- Автоматические вагонетки, транспортирующие добытую руду на склад.
- Продажа руды, улучшение шахтёров, вагонеток и их скорости, плавильня стали.
- Жесты масштабирования и перемещения карты, автосохранение локально.
- Интерфейс на русском языке, портретный режим Android.

Игра не использует графику, код или торговые марки Deep Corp.

## Сборка APK

1. Откройте вкладку **Actions** → **Android Debug APK**.
2. Запустите **Run workflow** (или дождитесь сборки после push).
3. В завершённом запуске скачайте артефакт **DailyCorp-debug-apk**, распакуйте ZIP и установите `DailyCorp-debug.apk`.

Это **отладочная сборка**. Для публикации нужен отдельный release-keystore. Для установки сборок, подписанных разными ключами, может потребоваться удалить старую версию приложения.

## Локально

Откройте `project.godot` в Godot 4.4.x. Для Android экспорта настройте Android SDK и JDK 17 в редакторе, установите export templates.

## Управление

- Тапните на блок камня/руды, **соседний с открытым тоннелем**, чтобы назначить добычу.
- Проведите пальцем для прокрутки карты; разведите пальцы для масштаба.
- Склад — продажа; Развитие — покупка рабочих, транспорта и техники.
- Автосохранение каждые 30 секунд, при сворачивании и выходе.
