# DailyCorp Native — новый Android-клиент без Godot

Первая полностью нативная сборка игры. Это **отдельное переписывание**, старую ветку `main` не изменяет.

## Технологии
- Kotlin + Android SDK (`Activity`, `View`, `Canvas`), **без Godot, Unity и игровых конструкторов**.
- `GameCore.kt` — чистая Kotlin/JVM-симуляция без Android-зависимостей.
- `MapCanvasView.kt` — собственная изометрическая отрисовка, масштабирование, перемещение и выбор зданий.
- `GameActivity.kt` — нативный UI, диспетчер транспорта, контракты, покупка и производство.
- Сохранение игры в локальном файле `dailycorp-native-v1.save`.

## Работает в первом вертикальном срезе
- 48 городов с постоянным seed и уникальной планировкой дорог.
- 248 определений ресурсов; генерация шахт с разной глубиной и конечными запасами.
- Шахты, склады, заводы, производственные рецепты.
- 4 вида **явно назначаемых** маршрутов грузовиков, без автоматической привязки.
- Контракты по городам, прогресс поставок и оплата после физической доставки.
- 10 эпох, очки науки, баланс компании.
- Свободное перемещение и масштабирование карты.

## Известные ограничения первого MVP
- Нет межгородских перевозок, стройки на новых участках, геологических этажей с отдельным 3D-экраном.
- Производимые товары выходят на городской склад; расширенная промышленная цепочка будет отдельным этапом.
- Графика сейчас генерируется кодом, без финальных рисованных спрайтов и освещения.
- Для улучшенной производительности крупных карт планируется батчинг тайлов/OpenGL ES.
- Формат сохранений альфы не совместим со старой Godot-версией.

## Сборка
Нужны JDK 17, Android SDK 35, Gradle 8.10.2. В GitHub Actions билд создаёт Android Debug APK.

`gradle --no-daemon :app:assembleDebug`

Тест независимого игрового ядра запускается через Kotlin CLI (`kotlinc`).
